- 新增 Claude Code 与 DeepSeek Harness 集成，与 Codex 一起提供独立检测、确认配置、Skill 更新、路径选择和移除操作。
- 多个 AI 客户端共用正式任务库，操作来源分别记录；强化多进程初始化与版本冲突保护。
- 配置操作绑定用户确认的路径，保留原有配置、权限和备份，遇到未知同名配置不覆盖。
- 删除不再使用的 Codex 专属界面、旧桥接入口和重复展示逻辑，保留旧安装迁移与权限保护。
- 整理中文 README，新增英文 README，更新下载、数据位置和云端发布流程说明。

验证：Rust 工作区 103 项测试、前端 83 项测试及生产集成适配测试通过。Codex 与 Claude Code 已验证真实客户端工具发现；DeepSeek Harness 桌面 0.2.0-rc.2 已由用户完成 list_projects 只读调用，其余工具及写入尚未在该客户端实测。

升级后在“连接与权限”中选择所需客户端并确认配置或更新，然后重新连接 MCP 或重启该客户端。移除集成只移除所选客户端的 TodoList 托管配置与 Skill，不删除任务数据。
