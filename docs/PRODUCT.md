# TodoList MVP

TodoList 是一个 Windows/macOS 本地优先桌面任务工具。没有 Codex 和 MCP 时，它仍可完整使用；连接后 Codex 只能按需读取、创建和更新任务。

首版主界面是左侧导航、中间任务区和右侧详情三栏。用户可以把任意任务主动置顶为独立的桌面便签窗口；Codex 创建任务后不会自动打开或置顶便签。

## 产品首版目标

- 项目、任务、子任务、日期、优先级、标签、依赖和验收标准
- 今日、进行中、项目列表与看板
- 本地 SQLite 和任务变更版本
- STDIO MCP 读取、创建、更新与项目内排序
- 可置顶的桌面便签窗口
- 不做 Todo 主动启动或继续 Codex
- 不做云同步、团队、移动端、提醒和重复任务

## 当前已落地的第一个垂直切片

- 可交互的三栏任务台和看板
- 新建/编辑任务、创建/编辑项目、当前视图搜索、完成/重新打开、归档、安全删除和用户置顶
- 新安装空白工作区；演示 seed 只用于显式浏览器演示和测试，桌面/MCP 不自动写入
- 附件与图片分别持久化；普通文件交给系统默认应用，图片使用叠卡与独立大图查看器
- 列表多选限定当前视图和搜索结果；普通列表批量归档，已归档列表批量永久删除
- 删除含任务项目时选择整体转移（可新建承接项目）或经两步确认级联永久删除
- 子任务与验收标准分别保存完成状态；未确认全部验收标准前不能完成任务
- 看板支持拖放与键盘可用的状态选择器
- 列表任务可通过左侧把手拖动或键盘上下键排序；搜索、今日、全部和归档等筛选只重排当前可见子集，不改变隐藏任务的相对槽位
- Tauri 原生窗口、Rust Task Core 与 SQLite WAL 存储
- 单一当前快照存储；不会因日常编辑次数不断累积整份任务库副本
- UI 写入遇到 MCP 版本冲突时保留外部新数据并重放用户的当前操作
- 桌面窗口空闲时仅检查 Workspace 版本，版本变化后才读取完整任务数据
- 可独立显示的 always-on-top 任务便签
- STDIO MCP 的项目/任务读取、任务创建、带版本检查的更新和项目/归档范围内的原子排序
- 项目内 Codex Skill 与“用户修改优先”的冲突规则

TodoList 端反向触发 Codex、云同步、细粒度项目授权和提醒仍属于后续里程碑；当前界面只显示服务与配置是否就绪，不伪装实时连接状态。

## 便利贴规则

- 只有用户操作才能置顶或取消置顶
- 可以同时显示多个置顶任务
- 侧栏“桌面便签”是独立入口，无置顶任务时也能打开；确认便签窗口打开成功后才最小化任务台
- 任务行和详情的置顶图标只调整置顶并显示便签，不最小化任务台或抢走焦点
- 顶部图标、文字和空白处均可拖动原生窗口，默认显示箭头光标；关闭按钮不属于拖动区
- 可以直接完成或重新打开任务
- 完成子任务不会自动完成父任务
- 主窗口关闭时，便签窗口仍可保留
- 便签中的“打开任务台”会恢复现有主窗口（包括最小化），主窗口已关闭时按原桌面配置重建；不会关闭便签或创建重复主窗口
- 便签只展示任务，不承载复杂编辑和 MCP 设置
- 归档任务时自动取消置顶；永久删除只在“已归档”中提供并需要二次确认
- 默认窗口约为 360 × 330，可由用户调整大小
