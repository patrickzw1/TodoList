# TodoList v0.1.0

首个 Windows x64 版本，面向个人日常试用。

## 功能

- 本地 SQLite 任务库，支持今日、全部、进行中、项目视图以及列表/看板。
- 新建编辑、独立子任务与验收确认、归档恢复、桌面置顶便签。
- JSON 备份与恢复，项目颜色反馈和有界活动记录。
- 可选 Codex MCP 集成；任务台关闭后 MCP 仍可独立读写，写入不会自动打开任务台。
- 设置中手动检查 GitHub 更新，安装前校验 Tauri 更新签名。

## 数据正确性修复

- 恢复备份为任务分配新版本，拒绝恢复前的过期 MCP 写请求。
- 完成操作在最新数据上检查验收条件，包括并发重试、连续排队操作与便签入口。
- 清单插入、删除和重排保留匹配项的状态，新增/改名项默认未完成。
- 桌面缓存失败不妨碍 SQLite 已成功的读写。

## 发布前验证

- 35 项前端回归、33 项 Rust 回归、4 项 Sites 测试通过；类型检查和生产构建通过。
- 发布安装包对应的 MCP sidecar 完成真实 STDIO 初始化和六个工具的 schema 冒烟。
- 最终浏览器资源验证了验收限制、插入条目的状态保留及项目颜色，未观察到控制台错误或警告。
- 使用与 Tauri updater 相同的验证库独立验证安装包签名；篡改单字节的副本验证失败。更新清单与安装包签名一致。

## 使用说明与范围

- 下载并安装 `TodoList_0.1.0_x64-setup.exe`。安装前退出 TodoList 和使用 TodoList MCP 的 Codex，释放后台 MCP 程序占用的文件；安装完成后可重新打开 Codex。
- 首次启动包含演示项目和任务。真实任务数据保存在本机，建议定期从设置导出备份。
- Codex 集成只在用户主动配置后启用；开发版迁移到安装版后可在连接与权限页迁移已有受管理配置，然后重启 Codex。
- 只提供 Windows x64 安装包。macOS 打包与行为尚未验收。
- 使用免费 Tauri 更新签名，尚无 Windows Authenticode 发布者证书，系统可能提示未知发布者。
- 自动化回归与浏览器验收不等于全套原生 Windows 安装、升级、拖动和文件对话框验收；长期资源使用仍需日常试用反馈。
