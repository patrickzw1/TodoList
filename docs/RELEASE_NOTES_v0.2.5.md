# TodoList v0.2.5

本次更新修复“未安排”任务偶尔错误出现在“今日”视图的问题，并统一桌面 UI 与 MCP 的无日期语义。

## 修复与兼容性

- “今日”现在只显示截止日期有效且不晚于本机当天的未归档任务。空日期、未安排日期、无效旧日期、未来日期和归档任务不会再误入。
- “未安排”和旧版无效日期仍保留在“全部”及对应项目中；升级不会补写、迁移或删除用户现存任务数据。
- MCP 创建任务时省略或传空日期都会保存为“未安排”；更新任务时传空日期会清除日期，不传日期字段则保留原值。
- MCP 会拒绝非空但无效的公历日期，并保证失败时不产生部分写入。

Windows 安装包继续使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名；macOS 仍未提供经过签名与安装验证的发布包。
