# TodoList v0.2.7

本次更新让桌面便签正确跟随窗口缩放，扩展项目颜色选择，并减少 Codex 日常读取任务时返回的活动历史数据。

## 新增与改进

- 桌面便签现在始终填满当前窗口，缩放时标题、内容区和底栏会稳定适配；内容不足或窗口变小时仍保持既有滚动和最小尺寸约束。
- 保留原有六种项目颜色，并新增“大红色” `#FF0000` 预设。新建项目、编辑项目和删除项目时新建承接项目均可使用同一套颜色选择。
- 项目颜色支持系统取色器以及 `#RGB`、`#RRGGBB` 输入；无效值不会保存，已有自定义颜色会原样保留并继续在界面中显示。
- MCP 的 `list_tasks`、`get_task`、`create_task` 和 `update_task` 普通返回不再携带 `activity`，但任务版本、清单稳定 ID、依赖、附件与图片元数据及其他字段保持不变。活动记录仍在本地数据库中保留最近 100 条。
- 新增只读 `get_task_activity` 工具：按最新记录优先读取单个任务的活动，默认返回 10 条、单页最多 50 条，并使用绑定任务版本的不透明游标；任务更新后旧游标会明确失效。

## 升级 Codex 集成

- `get_task_activity` 是第八个 MCP 工具。升级应用后，如果“连接与权限”显示“可更新”，请明确点击“更新集成”，再重新连接 MCP 或重启 Codex。
- 刷新会更新 TodoList 管理的 Skill，并仅为已知完整的旧版工具列表补充缺失工具；用户主动限制或自定义的工具权限保持不变。
- 正常读取任务不会自动调用活动历史工具。只有用户明确要求追溯记录时，Codex 才会按需要读取和翻页。

## 安全与兼容性

- 本次更新不新增数据库结构，也不会迁移、清空或复制现有任务及活动记录。
- 开发桌面、开发 MCP、正式安装和网页预览继续使用既有隔离边界。
- Windows 安装包继续使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名，因此系统仍可能显示未知发布者提示。
- macOS 仍未提供经过签名与安装验证的发布包。
