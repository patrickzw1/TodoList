# TodoList v0.2.23

## MCP 搜索与精简读取

- 支持按任务标题、描述、子任务、验收标准、标签、依赖说明和文件名搜索，并组合项目、状态、优先级、日期与归档筛选。
- 列表默认每页 15 条摘要；支持精确、包含、有界模糊匹配、排序、字段/分节读取和统计。子任务、验收项及文件命中带稳定 ID，便于后续局部操作。
- 提供工作区诊断与有界增量查询，返回变化的 ID/版本；游标过期或备份恢复时明确要求重新同步。

## MCP 写入与文件内容

- 支持单个及批量归档/恢复、任务字段调整、项目转移和项目改名/颜色修改，批量操作采用原子事务。
- 描述可追加、前插、唯一片段替换/删除；子任务与验收项可按 ID 局部修改。版本检查、重试防重、验收门槛及完成时间保护继续生效。
- 保留本机文件导入，新增小型 UTF-8 文本附件直接提交、关联文件列表和安全移除。
- 按需分段读取文本、PDF、DOCX、PPTX、XLSX，返回图片预览，并支持明确范围内的附件内容搜索。普通任务查询不会自动返回文件正文或图片。

## 兼容与边界

- MCP 工具扩展为 17 个。更新安装后，在“连接与权限”中确认更新已配置的 AI 集成，再重新连接 MCP；自定义工具限制保持不变。
- 列表默认使用摘要，写入默认返回简短结果。旧调用方需要完整字段时使用 `projection=full` 或 `response=full`；单任务 `get_task` 默认仍返回完整详情。
- 文档采用有界文本提取，不执行宏、脚本、外链或公式，不还原 Office 视觉排版。扫描页/图片需要 OCR 时明确提示；不提供云 OCR，旧二进制 DOC/PPT/XLS 不支持。
- Codex 与 Claude Code 的隔离图片协议链路已有验证；DSH 的实际图片链路及客户端 UI 渲染仍未验证。协议成功不等于图片已被模型识别。
- 文件路径仅在响应时解析；文件占用等导致副本尚未回收时返回实际待清理状态。

接口、分页与同步说明见 [MCP API](MCP_API.md)。安装包由 GitHub Actions 构建和发布。
