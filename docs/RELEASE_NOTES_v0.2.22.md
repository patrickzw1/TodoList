# TodoList v0.2.22

## 改进

- 任务详情新增完成时间，按本机时间显示完整日期与时分秒。
- 已完成任务在列表、看板和桌面便签中显示完成日期，不再显示逾期天数；原截止日期保持不变。
- 完成时间独立保存，普通编辑、归档和排序不会改变。重新打开任务会清除当前完成时间，再次完成时重新记录。
- 兼容旧任务与备份：仅从可靠的完成记录恢复旧完成时间，无法确定时显示“已完成（时间未记录）”。
- MCP 任务结果同步包含 completedAt，并保护桌面与 MCP 并发编辑时的完成时间。

## 验证

前端 87 项回归、Rust 工作区测试、类型检查、前端生产构建与 Sites 检查通过。开发浏览器已验证列表、详情、编辑器、看板和便签的完成/重开流程及窄窗口布局。安装包由 GitHub Actions 构建发布。
