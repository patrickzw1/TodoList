# TodoList v0.2.11

修复旧版本晚发布导致软件无法发现更高版本的问题。

## 更新检查

- 客户端分页读取公开正式版本，按语义版本号选择最高版本，不依赖 GitHub Latest 标记、发布时间或列表顺序。
- 忽略草稿、预发布及无效版本；已安装相同或更高版本时不会降级。
- 读取选定版本固定标签下的更新清单，并检查清单版本与更新资源来源。
- 最高版本缺少资源、查询超时或限流时明确提示失败，不回退到旧版本或误报已是最新。
- 保留原有检查间隔、主动下载安装、Tauri 签名验证与开发通道隔离。

## 验证与升级

Rust 35 项、前端 71 项测试及类型检查通过。Windows 构建、更新签名与安装包校验由 GitHub Actions 执行。

该逻辑在安装本版本后生效。若旧版仍被 GitHub Latest 标记指向的较低版本阻挡，可从本 Release 手动下载安装包升级。

本次未修改发布脚本，不改变任务数据库。安装包继续使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名。
