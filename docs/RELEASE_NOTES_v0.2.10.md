# TodoList v0.2.10

本次更新调整任务详情的图片堆叠，并修复 GitHub Release 草稿定位与发布流程。

## 改进

- 图片主卡居中显示，两侧背卡错位展开，使用轻微的 2.5° 倾角。
- 缩略预览完整显示图片；展开详情时保持紧凑尺寸，左右切换按钮靠近图片。
- 保留顺序切换、点击主图查看大图及既有附件、图片数据。

## 发布流程修复

- 创建草稿后直接使用返回的 Release ID 上传和校验资源，避免立即查询列表无法找到新草稿而中断。
- 修复 Windows PowerShell 5.1 的发布列表数组解析，保留草稿归属、资源哈希和版本标签校验。
- 为暂时失败的读取请求增加有限重试；创建和发布操作不自动重复执行。

## 验证

图片堆叠已通过浏览器验收。发布脚本已通过模拟回归；实际 Windows 构建、更新签名和安装包校验由 GitHub Actions 执行。

本次不改变任务数据库。Windows 安装包继续使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名。
