# TodoList v0.2.2

本次版本改善任务较多、看板内容较长以及详情文字较长时的浏览体验。

- 今日、进行中、全部、项目和已归档等任务列表会在任务台可用高度内纵向滚动，并使用自动隐藏的细蓝灰色滚动条。
- 看板的每个状态列可以独立纵向滚动，不会带动相邻列；窄窗口下的横向看板滚动也沿用相同的滚动条样式。
- 任务描述保留手动换行，较长的文件路径、URL、英文标识符和中文文本会在详情内换行；长标题不会遮住标题操作。
- 任务详情可临时展开到任务台工作区宽度，并在同一位置收起；关闭详情后再次打开会恢复正常宽度。

本版本未增加 MCP 文件上传或附件导入能力；附件和图片仍通过桌面界面添加，MCP 只读取其元数据并在更新任务时保留这些字段。

本次发布准备已通过 TypeScript 检查、43 项前端应用回归、4 项 Sites 检查、47 项 Rust workspace 回归、前端生产构建，以及 Windows x64 正式 GUI、MCP 和 NSIS 打包。正式产物已通过现有 Tauri updater 公钥对应的签名、更新清单、SHA-256、GUI/MCP 版本与运行身份、Windows PE 子系统和个人构建路径扫描；生产 MCP 也通过了使用临时数据库的 STDIO 检查。本次未重复运行会安装应用或显示安装界面的完整安装器交互验收。

更新包继续使用 Tauri updater 签名保证完整性。本阶段未使用 Windows Authenticode，Windows 仍可能显示“未知发布者”。
