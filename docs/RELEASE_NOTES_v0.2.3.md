# TodoList v0.2.3

本次更新让任务顺序可由用户和 Codex 安全调整，并把软件版本与更新状态集中到侧栏和设置页。

## 新增与改进

- 列表行左侧增加紧凑排序把手，支持 Pointer Events 拖动、插入提示、浮动预览、长列表边缘自动滚动，以及键盘上下方向键排序。
- 今日、全部、进行中、项目、已归档和搜索结果都只重排当前可见子集；隐藏任务、其他项目和另一归档状态的相对槽位保持不变。
- 新增 MCP `reorder_tasks` 工具。它使用完整稳定 ID 顺序和 Workspace 版本进行原子校验，不改变任务字段、状态、项目、归档状态或任务版本。
- `list_tasks` 改用版本化不透明游标；排序或其他并发修改后，旧游标会明确失效，避免跨版本分页得到混合顺序。
- 侧栏不再展示内部 Workspace revision。设置入口显示真实软件版本，并在发现更新时显示安静的蓝色徽标。
- 项目较多时，侧栏项目区域会独立滚动且始终隐藏滚动条；新建任务和主要导航固定在上方，桌面便签、设置及保存状态固定在下方。
- 正式桌面启动后会非阻塞检查更新，并以六小时节流在窗口重新获得焦点时复查；网页预览不访问桌面更新源。
- 下载和安装仍只在用户点击后开始。离线或检查失败不会被误报为“已经是最新版本”。

## 安全与兼容性

- 新任务继续追加到现有共享顺序；旧任务顺序无需迁移即可保留。
- 无变化、取消或无效的排序不会增加 Workspace revision，也不会重写 SQLite 快照。
- MCP 会拒绝过期 Workspace 版本、重复/缺失 ID、跨项目和跨归档状态输入，失败时不产生部分写入。
- 附件与图片能力没有扩大：MCP 仍只返回元数据，不能上传、导入、删除或预览文件。
- 开发桌面、开发 MCP、正式安装和网页预览继续使用既有隔离边界；本次验证不写入日常数据库或全局 Codex 集成。

## 升级后启用 Codex 排序

- v0.2.3 新增了第七个 MCP 工具 `reorder_tasks`。升级应用后，请在“连接与权限”中确认并刷新 TodoList 管理的 Codex 集成，然后重新连接或重启 Codex，才能在现有配置中使用该工具。
- 刷新只更新 TodoList 管理的 Skill 和 `todolist` MCP 条目，并保留其他 Codex 设置与 MCP 服务；应用不会在升级时自动修改用户的全局配置。

## 已知范围

- Windows 安装包使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名，因此 Windows 仍可能显示未知发布者提示。
- macOS 仍未提供经过签名与安装验证的发布包。
