# TodoList v0.2.16

- 首次读取明确区分加载中、失败和成功空库；加载失败时阻止任务写入，并提供重试与只读存储诊断。
- 外部修改同步增加读取超时、错误及恢复提示。
- GUI 和 MCP 新增本地诊断日志，保存于各自可执行文件旁的 logs 文件夹。日志记录关键状态和计数，过滤任务内容与敏感路径，限制文件大小并清理旧日志。
- 设置及加载失败页提供日志状态、打开日志目录和 15 分钟临时详细日志。安装目录不可写时明确提示，不回退到其他目录。

此版本增强了故障防护和诊断能力。此前正式版界面为空的具体根因尚未确认，需要在更新后结合实际日志进一步定位。

更新后如仍无法显示任务，请打开“查看存储诊断”，并保留安装目录 logs 中的日志。无需清空缓存、重建项目或修改数据库。
