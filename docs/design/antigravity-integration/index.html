配置位置

MCP 注册
~/.gemini/config/mcp_config.json 中的 mcpServers.todolist。command 使用安装版 todolist-mcp.exe 的绝对路径。
全局 Skill
~/.gemini/config/skills/todolist-mcp/SKILL.md。此全局目录由 Antigravity App 与 CLI 共用，确认时显示完整路径与作用范围。

配置与移除流程

  1. 选择 Antigravity

    只读检测客户端、MCP 注册和 Skill。自动定位失败时，用户可以从 Antigravity 的「Copy Config File Path」取得配置路径，并在 TodoList 检查实际使用的绝对路径。

  2. 按读取结果提供操作

    • 缺少托管内容时，配置或补齐缺少的一项。
    • 识别出当前托管内容后，可以原位更新或移除。命令路径迁移须核对旧归属并单独显示变更。
    • 同名项归属不明、文件读失败或路径未检查时，保留内容并提示重新检查。

  3. 确认本次操作与两条路径

    确认只对所选客户端及所示路径有效。切换客户端、修改路径或刷新失败后，取消该确认。

  4. 保存后重新读取磁盘

    仅合并或移除本应用拥有的 mcpServers.todolist 和 Skill，保留其他注册及现有工具限制。原位更新使用现有 JSON 恢复机制。内容已一致时直接返回。写入中断时恢复已改文件并报告当前状态。

  5. 在 Antigravity 重新加载

    配置或更新后，用只读 list_projects 验证调用，记录 Antigravity 版本、sidecar 构建及工具结果。移除后重新加载，确认本次注册和 Skill 已不再出现。

状态与操作

状态呈现与处理
读取中或读取失败保持操作禁用，刷新成功后恢复。客户端未发现时提供手动核对路径入口。
未配置或不完整分别显示 MCP 注册、Skill 状态，提示可配置或补齐的部分。
可更新或待迁移列出将修改的托管项。保留 disabled、enabledTools、disabledTools 和每个工具的现有设置。
同名冲突标明冲突来自注册还是 Skill，保留冲突内容。用户处理后刷新状态。
配置已同步磁盘状态可确认。运行默认显示未验证，客户端实际成功调用后才记录该次 list_projects 验证。
移除后分别刷新注册与 Skill。其他客户端、全局设置、其他服务器和任务数据保留。
