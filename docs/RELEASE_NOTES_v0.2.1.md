# TodoList v0.2.1

本次版本增强 Windows 更新可靠性，重点保证 TodoList 主程序与 MCP 作为同一组组件完成替换。

- 更新时只关闭目标安装目录中的 TodoList GUI 与 MCP，不关闭 Codex，也不影响开发版或其他安装目录中的同名进程。
- GUI 与 MCP 先完成成对校验再提交安装；更新期间 MCP 若被重新拉起，会返回可重试的更新中状态。
- 安装成功后等待安装器退出，再清理该次自动更新的专属安装包缓存；暂时无法清理不会把成功安装误报为失败，后续启动会安全重试。
- 安装失败会恢复旧组件、保留已验证安装包并打开其所在位置一次，方便手动重试；取消安装与下载失败分别处理。
- 设置页区分检查、下载与验签、安装以及组件一致性状态，并提供保留安装包的重试和清理入口。

更新包继续使用 Tauri updater 签名保证完整性。本阶段未使用 Windows Authenticode，Windows 仍可能显示“未知发布者”。
