# TodoList v0.2.9

本次更新改善任务详情中子任务和验收标准的阅读体验。

## 改进

- 每条清单之间增加浅灰分隔线，并保留上下间距，最后一条不显示分隔线。
- 复选框对齐正文第一行；长内容自然换行，各行左侧对齐，避免相邻条目看串。
- 移除子任务右侧重复的状态文字，已完成条目使用勾选、淡色文字和删除线区分。
- 保留现有勾选操作、子任务完成数量和验收限制，不改变任务数据库或 MCP 协议。

## 验证范围

类型检查、21 项相关行为测试及浏览器验收通过，覆盖窄面板、展开详情、长文本、键盘勾选和固定顶栏/底栏。未进行本次原生 WebView 视觉验收。

Windows 安装包继续使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名。
