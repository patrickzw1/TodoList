# TodoList v0.2.4

本次更新让已有 Codex 集成的升级状态更准确，并减少 Windows 更新安装期间额外出现的控制台窗口。

## 改进

- 当前安装路径未变化时，旧版托管 Skill 会显示为可选的“更新集成”，不再误报为修复失败；完成后会列出实际更新的内容。
- 完整工具列表按集合比较，顺序变化不会触发误报。旧版受管集成的完整六工具配置可在确认同步新版说明时补充排序工具。
- 用户限制过的工具白名单和未设置白名单的默认权限都会保留。类型错误、含非字符串元素或重复项的 `enabled_tools` 会明确显示为配置不完整，且不会被自动覆盖。
- 安装协调及后台清理进程不再额外创建控制台窗口。正常安装界面和 Windows UAC 提示仍按系统需要显示。

## 安全与兼容性

- Codex 集成仍只在用户明确点击后写入；路径迁移、缺失项、未知配置、文件读写错误继续分别报告。
- “配置已同步”只表示磁盘上的 MCP 与 Skill 配置一致，不代表 Codex 当前已连接。
- Windows 更新仍只处理目标安装目录内的 TodoList GUI 和 MCP，并保持既有事务回滚、失败安装包保留及一次 Explorer 恢复入口。
- 开发桌面、开发 MCP、正式安装和网页预览继续使用独立数据与集成边界。

## 升级后

- 如果“连接与权限”显示“可更新”，点击“更新集成”后重新连接 MCP 或重启 Codex，使新版 Skill 和工具列表生效。
- Windows 安装包继续使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名，因此系统仍可能显示未知发布者提示。
- macOS 仍未提供经过签名与安装验证的发布包。
