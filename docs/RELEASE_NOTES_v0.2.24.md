# TodoList v0.2.24

## 任务台与详情

- 项目任务列表对齐任务和日期，保留手动拖动、多选和置顶。可按项目分组，也可按创建时间、截止日期、完成时间或更新时间排序。
- 任务详情优先展示标题、状态、优先级和截止日期。长描述默认显示前四行，可以原地展开和收起。编辑器和 MCP 继续使用完整原文。
- 桌面便签、看板、编辑器和设置沿用任务台的排版、颜色及操作样式。

## 客户端集成与更新

- “连接与权限”支持配置、更新和移除 Google Antigravity 的本地 TodoList MCP 与 Skill。
- 更新已托管的 Skill 时替换当前版本，保留用户自定义配置；识别到的旧托管备份移出客户端的技能发现目录。
- 更新检查在重启后记住请求和冷却时间。GitHub 限流时显示何时可以重试；正式版本继续按版本号选取。
