# TodoList v0.2.8

本次更新改善任务详情覆盖层、滚动条一致性与桌面便签缩放体验，并让 Codex 集成更新提示更清晰。

## 修复与改进

- 任务详情打开时，鼠标滚轮和触控板滚动仍由指针下方露出的任务列表或看板列自然处理；点击露出区域会关闭详情，但不会误选任务、切换状态或开始拖拽。
- 普通及展开状态的任务详情使用固定标题栏和固定操作栏，仅中间内容独立滚动。长标题及较矮窗口中，展开/收起、置顶、编辑、关闭以及底部操作仍保持可见。
- 列表、看板列、任务详情、设置、连接与权限、对话框、编辑文本框、图片画布和桌面便签统一使用自动隐藏的细蓝灰色滚动条；侧栏项目列表继续保持滚动条永久隐藏但可滚动。
- 桌面便签的 Windows 原生窗口与 WebView 改用匹配页面的非透明暖白背景，用于减少横向缩放时的灰色背景闪现，同时保留可缩放、最小尺寸、始终置顶、标题拖动和关闭行为。便签原生横向缩放效果尚未完成实机视觉验收，本次已通过编译和窗口配置检查，实际效果需更新后确认。
- “连接与权限”与“设置”共用可滚动页面结构；只有受管理的 Codex 集成确实处于 `update_available` 时，侧栏才显示紧凑的“可更新”徽标。

## 安全与兼容性

- 本次更新不改变任务数据库结构、MCP 工具协议或用户数据，也不会自动修改 Codex 集成。
- 开发桌面、开发 MCP、正式安装与网页预览继续使用既有隔离边界。
- Windows 安装包继续使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名，因此系统仍可能显示未知发布者提示。
- macOS 仍未提供经过签名与安装验证的发布包。
