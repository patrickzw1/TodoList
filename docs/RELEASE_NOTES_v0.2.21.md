# TodoList v0.2.21

## 改进

- MCP 的附件和图片元数据新增 `localPath` 与 `localPathStatus`，AI 客户端可通过获准的本机文件工具读取托管副本。
- 任务列表、详情、创建重试、更新及附件/图片导入结果统一返回路径；缺失或不安全的文件返回空路径，不影响其他任务内容。
- 路径按当前数据库与开发/正式通道解析，只在响应时生成，不写入数据库或备份；不会把文件正文或图片数据自动发送给 AI。
- 同步更新 Codex、Claude Code、DeepSeek Harness 的 Skill 提示及中英文文档。

## 更新后

在“连接与权限”中按提示更新已配置客户端的集成，然后重新连接 MCP 或重启对应 AI 客户端。路径属于运行 MCP 的电脑，远程客户端不一定能够访问；返回路径不代表 AI 已读取文件内容。

## 验证

MCP 单元回归 20 项通过；开发阶段已通过 Rust 工作区、生产特性编译与隔离 STDIO/多客户端检查。安装包由 GitHub Actions 构建发布。
