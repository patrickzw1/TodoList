# TodoList v0.2.12

任务编辑器中的子任务、验收标准和依赖关系改为逐项添加与编辑。

## 改进

- 三个区域纵向排列，点击添加按钮新增独立条目并自动聚焦，条目内按 Enter 只换行。
- 每项支持多行内容，删除按钮固定为 32×32 并垂直居中，不随文本框高度拉伸。
- 新增空项保存时忽略；已有条目清空时提示填写或明确删除；取消编辑不保存改动。
- 修改子任务或验收标准文字时保留原有 ID 与完成状态，保存冲突时保留未编辑条目的并发修改和新增，不复活已被并发删除的条目。
- 详情中的多行条目和长文本正确换行，依赖关系保留原有含义。

## 验证

前端 71 项测试、类型检查、前端构建与 Sites 检查通过；主审独立运行的 27 项任务及存储回归通过。浏览器验证覆盖多行编辑、空项、取消、键盘焦点、窄窗口滚动和删除按钮尺寸。未执行本次原生 WebView 视觉验收。

本次不修改数据库结构或 MCP 协议。Windows 构建和安装包校验由 GitHub Actions 执行，安装包继续使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名。
