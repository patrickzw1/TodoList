# TodoList v0.2.0

本次更新增加任务资料管理和批量操作，继续提供 Windows x64 试用版本。

- 任务详情分别管理附件与图片：附件保留文件名、类型和大小，使用默认应用打开；图片以叠放卡片展示，两侧切换、中央打开大图，支持键盘导航和缩放。
- 文件复制到应用自己的资料目录，原文件不会被移动或删除。附件导入与任务关联在同一数据库事务内完成；删除清理会重新检查最新引用，避免并发操作误删资料。
- 普通列表支持多选和当前搜索结果全选后批量归档；已归档列表支持多选后确认永久删除。
- 删除含任务的项目时，可保留任务并转移到已有或新项目，或再次确认后连同任务删除。
- 首次启动使用空白任务库。升级保留已有数据；开发版使用独立数据库和 WebView 存储，不再与日常安装版混用。
- MCP 的工具描述、初始化说明和 Skill 已补充附件与图片能力：能读取元数据，更新任务时保留文件；当前通过桌面界面添加文件，MCP 不提供上传接口。
- 修复 Windows 附件打开命令、图片查看器键盘焦点循环，并校验备份中的文件内容是否齐全。

升级前退出 TodoList 和使用其 MCP 的 Codex。安装后，如果“Codex 集成”提示 Skill 需要更新，点击配置操作完成更新，再重启 Codex。

JSON 备份目前整体上限为 25 MB（含文件的 base64 内容），大附件可能导致备份超过上限。单个导入文件上限为 100 MB。macOS 尚未提供经过验证的安装包。Windows 安装包使用 Tauri 更新签名，暂未配置 Authenticode 发布者签名。
