# TodoList v0.2.13

Codex 现在可以通过 MCP 将本地文件实际添加到任务的附件和图片区域。

## 新增

- add_task_attachment：将 MCP 所在电脑上的本地文件复制为任务附件。
- add_task_image：将支持的本地图片复制到任务图片区域。
- 保留源文件，复用现有 100 MB 文件限制和独立通道存储；返回元数据，不返回文件正文。
- 支持任务版本冲突检查与稳定请求 ID 的幂等重试，避免重复添加；失败时安全清理本次未关联副本。
- 同步工具说明、集成 Skill 和旧工具清单的更新提示。移除、打开及预览文件仍通过桌面界面完成。

## 使用方式

安装后，在“连接与权限”中点击“更新集成”，随后重新连接 MCP 或重启 Codex，让新工具生效。提供需要添加的本地文件路径和目标任务即可；仅把路径写进描述仍不等于添加附件。
